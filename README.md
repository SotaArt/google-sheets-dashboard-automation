# Автоматизация управленческого дашборда в Google Sheets

<b>О проекте</b>
#
Проект разработан для автоматизации управленческой отчетности подразделения и контроля ключевых показателей эффективности сотрудников.
Основная задача решения — сократить ручную подготовку отчетности, повысить прозрачность данных и ускорить принятие управленческих решений.
#

<b>Бизнес-задача</b>

До внедрения:
- данные собирались вручную из нескольких таблиц
- расчеты выполнялись вручную
- руководитель получал информацию с задержкой
- присутствовал риск ошибок
- отсутствовал единый аналитический инструмент

После внедрения:
- единый дашборд
- автоматический расчет показателей
- актуальные данные
- визуализация KPI
- сокращение ручной работы

---

<b>Реализованный функционал</b>

В рамках проекта реализовано:
- автоматический сбор данных
- расчет выполнения KPI
- анализ отклонений
- контроль план/факт
- динамика по датам
- рейтинг сотрудников
- визуализация метрик
- автоматическое обновление показателей

---

Используемые инструменты
- Google Sheets
- Google Apps Script
- Формулы Google Sheets
- Business Analysis
- Process Automation
- Data Visualization

---

<b>Моя роль</b>

В рамках проекта самостоятельно выполнил:
- анализ бизнес-потребности
- проектирование структуры дашборда
- разработку логики расчетов
- настройку автоматизации
- визуализацию показателей
- тестирование решения
- внедрение в рабочий процесс

---

<b>Результаты</b>

После внедрения удалось:
- сократить время подготовки отчетности с нескольких часов до 10–15 минут
- снизить количество ошибок
- повысить прозрачность показателей
- ускорить управленческие решения
- снизить операционную нагрузку
