# google-sheets-dashboard-automation
Автоматизация управленческой отчетности и KPI dashboard в Google Sheets


Описание проекта

Проект представляет собой систему автоматизированной управленческой отчетности для контроля KPI подразделения.

Дашборд позволяет:

- автоматически собирать данные
- рассчитывать показатели
- контролировать выполнение плана
- анализировать отклонения
- визуализировать ключевые метрики

Бизнес-задача

До внедрения:

- данные собирались вручную
- отчеты занимали несколько часов
- возникали ошибки
- отсутствовала прозрачность

После внедрения:

- единый источник данных
- актуальные показатели
- сокращение ручной работы
- ускорение принятия решений

Используемые инструменты

- Google Sheets
- Google Apps Script
- Data analysis
- KPI analytics
- Process automation

Результат

Время подготовки отчетности сокращено с нескольких часов до 10–15 минут.

Моя роль

В рамках проекта:

- анализ требований
- проектирование структуры
- разработка логики
- автоматизация
- тестирование
- внедрение
